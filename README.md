# Visual Inspection Deep Learning & Model Serving

Independent Python/PyTorch defect detection and local FastAPI inference. Implementation
and experiments are in progress; final measured results will be recorded before release.

The scope and acceptance criteria are in [IDEA_PACKAGE.md](IDEA_PACKAGE.md). This
repository is independent of the existing Visual Inspection Platform. Its frontend,
database, queues, and human-review workflows are outside this implementation.
